# Pathology Audit Web UI

Put these files in your project root:

```text
webui.html
webui.py
```

Open directly:

```text
double click webui.html
```

Or run local server:

```bash
python webui.py
```

Then open:

```text
http://127.0.0.1:7860/webui.html
```

This UI is a static demo view. It draws synthetic patch-like images and heatmaps in browser canvas.
